# Maintenance Guide — Nuisance Codes and Intermittent Faults
codes: P0128, P0401, P0420, P0101, U0100
system: maintenance

## Definition
A nuisance code is one that sets and clears on its own, recurs on the same unit, and
never coincides with abnormal metrics or driver complaints. Chasing them wastes shop time
and trains dispatchers to ignore alerts, which is how real faults get missed.

## How to recognise one
1. The code becomes inactive within about an hour without a repair.
2. Coolant temperature, oil pressure and battery voltage stay in their normal bands
   throughout (185–205 °F, 40–60 psi, 13.8–14.4 V).
3. The same code has appeared on the same vehicle at least twice before.
4. No high-severity code appears in the same window.

## Handling
- Do not open a work order. Add a note to the vehicle's record and bundle the code with
  the next scheduled preventive maintenance.
- If a manager rejects an alert for the code as "known intermittent", suppress further
  alerts for that code on that vehicle unless metrics change or a related high-severity
  code appears.
- Re-evaluate quarterly: a nuisance code that starts appearing with rising temperature or
  falling voltage is no longer a nuisance.

## Typical nuisance codes in this fleet
P0128 (thermostat, cold mornings), P0401 (EGR, low-load city routes), P0420, P0101 after
filter service, and single U0100 events during engine start.
